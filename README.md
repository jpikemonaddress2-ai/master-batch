# master-batch

マスターバッチ（樹脂に添加剤を指定濃度で練り込む作業）向けの、配合計算と造粒条件記録アプリ。

- **配合計算** — 添加濃度と作成量を入れると、各原料の仕込み量を出す。原料の有効成分%を持つので、既製MB（例: 有効成分50%）を使う場合の換算ミスを防ぐ
- **造粒条件の記録** — サンプル1バッチごとに、狙い値・実秤量・造粒条件・評価結果を記録する
- **検索と比較** — 条件で絞り込み、選んだサンプルを列に並べた転置表で比較する

社内LANの1台で動かすアプリ。Node（v22.5 以降）の標準モジュールのみを使い、npm 依存はゼロ。

## 起動

`start.bat` をダブルクリックする（または `node server.mjs --open`）。ブラウザで http://localhost:5173 が開く。
データは `data/masterbatch.db` に保存される。バックアップはサーバーを止めてこのファイルをコピーする。

社内LANの他のPCから開けるようにするには、`config.mjs` の `HOST` を `'0.0.0.0'` にして再起動し、Windows ファイアウォールでの許可を受ける。
他のPCからは `http://<このPC名>:5173` で開く。
